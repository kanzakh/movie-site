# Second Feature

A movie discovery site built with React + Vite, using the TMDB API.

## Setup
1. `npm install`
2. Get a free API key at https://www.themoviedb.org/settings/api
3. Copy `.env.example` to `.env` and paste your key as `VITE_TMDB_KEY`
4. `npm run dev`

Build for production with `npm run build`.
